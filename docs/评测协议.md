# 图纸审查评测协议

评测单位为“案例、规则、对象”。本版本协议用于合成结构化输入，旨在检验问题检出、对象定位与指定证据引用，不评价真实工程安全。

## 输入与规则

`geometry`包含构件的两个横坐标，单位固定为毫米；`dimension`包含标注值和单位，可能缺失；`layer`包含图层名称。几何和标注代表不同证据来源，SVG仅是便于阅读的示意图，不按比例绘制，不作为解析输入。

| 规则 | 定义 | 需要引用的证据 |
|---|---|---|
| DEMO_DIM | 尺寸标注换算为毫米后，与几何长度之差大于5毫米 | geometry-1、dimension-1 |
| DEMO_LAYER | 图层名称不是DEMO_COMPONENT | layer-1 |

只支持mm与cm。缺失尺寸或未知单位时，演示基线返回`abstain`，不把这类输入认定为已检查无问题。本协议采用整例转人工，尚未支持部分规则已检查、部分待复核的复合状态。

## 输出

```json
[
  {
    "case_id": "case-050",
    "status": "complete",
    "findings": [
      {
        "rule_id": "DEMO_DIM",
        "entity_id": "component-1",
        "evidence_ids": ["geometry-1", "dimension-1"]
      }
    ]
  }
]
```

`complete`与空意见列表表示支持范围内检查完毕且无问题。`abstain`须配空意见列表，可加`reason`。未知案例、重复案例或不合格字段会报错；重复意见不会去重获利，多余意见计误报。遗漏案例不会从评测分母剔除：其问题计漏检，案例判断计错误。

## 指标与匹配

意见按`rule_id`与`entity_id`精确匹配，不采用宽松文本相似度。采用计数匹配：每条真值最多匹配一次，多余重复计FP。

- 精确率＝TP／（TP＋FP）；召回率＝TP／（TP＋FN）。
- 有指定证据的召回率＝既匹配问题又具备完整指定证据的意见数／真值问题数。
- 正常误报率＝产生任何审查意见的正常案例数／正常案例数。错误转人工另计入案例决策错误，不伪装为误报。
- 证据不足正确转人工率＝正确输出abstain的证据不足案例数／证据不足案例数。
- 覆盖率＝输出complete的案例数／全部案例数；应结合错误率看待，不能靠提高覆盖率牺牲可靠性。
- 案例决策正确须同时满足状态正确、意见计数正确、每条命中意见引用完整指定证据。

证据ID须存在于该案例中，且集合恰好等于该问题要求的证据集合。只引用一个存在但无关的图层ID，不能作为尺寸意见的证据。这个检查不覆盖证据内容的语义推理或真实图纸定位质量。

分母为零时输出null，避免将无问题数据集的召回率填成100%。报告给出计数、各注错类别结果和逐例差错记录。案例级Wilson 95%区间只是统计计算示例：同族变体有关联，真实研究应采用足够多的独立图纸项目和相应分组统计方法。

## 演示验收门槛

本版本自行设定：无漏交案例；精确率、召回率、有证据召回率均至少95%；命中意见全部具备指定证据；存在正常和证据不足样本；正常误报为零；证据不足全部转人工。程序只输出`demo_gate_pass`，工程验收始终标记未建立。

这些数值用于说明怎样将门槛变成可执行判断，未经风险论证和行业认可。真实验收需补足专业范围、危险漏检权重、图纸解析误差、人机责任、超时处置、模型变更回归及代表性外部数据。
